# 钻孔数据三维体渲染系统

面向地勘队的钻孔数据三维可视化与储量估算工具。纯浏览器运行 (TypeScript + WebGPU), 数据保存在本地浏览器, 无需服务器。

## 功能

| 页面 | 功能 |
|------|------|
| 项目列表 | 项目增删改 / 复制, localStorage 持久化, JSON 导出导入, 一键生成演示数据 |
| 钻孔管理 | 孔口表 / 测斜表 / 品位表 CSV 导入 (文件或粘贴), 格式错误行逐条报出行号与原因, 交叉校验 |
| 插值建模 | 反距离加权 (IDW) 插值到三维规则网格, 分辨率 / 幂次 / 搜索半径 / 最大点数可调, Web Worker 后台计算带进度; 按边界品位计算矿体体积、矿石量、金属量, 导出储量报表 CSV |
| 体渲染 | WebGPU 光线步进体渲染, 可拖拽节点的传输函数编辑器 (颜色 + 不透明度), 钻孔轨迹按品位着色叠加显示, 轨道相机 (旋转 / 缩放 / 平移) |
| 剖面分析 | 任意产状 (倾向 / 倾角 / 偏移) 剖面, 品位填色 + 等值线 (marching squares), 钻孔交点标注, 导出 PNG |
| 设置 | 渲染分辨率 / 步进数 / 背景色, 默认值, 环境检测, 数据清除 |

## 技术要点

- **插值**: IDW, `src/idw.ts` 中 `idwNaive` (全量扫描参考实现) 与 `idwIndexed` (均匀网格空间索引加速实现) 对同一查询点选取完全相同的邻域样本并以相同顺序做 float64 累加; `tests/idw.test.ts` 核对两者在随机数据上的最大误差 < 1e-6。
- **轨迹**: 最小曲率法 (minimum curvature) 测斜计算, 方位角自北顺时针, 倾角向下为正。
- **体渲染**: WGSL 光线步进, rg8 纹理 (归一化品位 + 有效掩码), 传输函数为 256 级 RGBA LUT 纹理, 拖动节点只更新 1KB LUT, 256³ 网格交互流畅; 按需渲染 (状态变化才重绘)。
- **储量**: 体素计数 × 体素体积得矿体体积, 乘体重得矿石量, 按平均品位折算金属量 (% → 吨, g/t → 千克); NaN 网格点不参与。
- **持久化**: 项目数据存 localStorage, 插值网格 (可达 64MB) 存 IndexedDB。

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm run test       # 单元测试 (插值核对 / CSV / 轨迹 / 储量 / 等值线)
npm run typecheck  # 类型检查
npm run build      # 生产构建
```

需要支持 WebGPU 的浏览器 (Chrome / Edge 113+)。

## CSV 格式

- 孔口表: `孔号, X, Y, Z[, 孔深]`
- 测斜表: `孔号, 测深, 方位角(0~360), 倾角(-90~90, 向下为正)`
- 品位表: `孔号, 自(m), 至(m), 品位`

首行可为表头 (自动识别跳过); 支持逗号 / 分号 / 制表符分隔; `#` 开头为注释行。
